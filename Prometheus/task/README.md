# CRM RAG 系统需求卡片索引

模拟 iCafe 卡片集合，用于教学，帮助建立"企业级 RAG 系统日常需求长什么样"的直觉。所有客户信息、事故细节、人名均为虚构，不对应真实事件。

每张卡片都补充了：发现渠道（谁、通过什么方式发现的）、客户/业务方反馈原话或场景、排查人、排查过程、根因、解决方案——重点看"排查过程"，那是真实工作中最花时间、也最能建立直觉的部分。

## 分类直觉

真实团队里，卡片数量比例大致如下：

- **知识库/数据摄取** 和 **检索召回优化** 两类合计占比最高（约 1/3），因为 RAG 系统本质是"数据 + 检索"的工程问题，不是"模型"问题。
- **安全/权限** 类卡数量不多，但一旦出现必是 P0，是企业级和 Demo 级 RAG 最大的分水岭。
- **稳定性/性能** 类卡往往在压测或大促前突然密集出现，平时不显眼。
