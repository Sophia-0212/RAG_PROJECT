  4. 安全检索、重排、上下文与引用
     实现检索前的强制权限过滤、可调混合召回、分数保留、去重、父子块扩展、上下文 Token 预算以及精确到文档版本的引用。

     完善状态模型，保留原始问题和改写历史；增加步骤、检索、生成、Token 和截止时间预算；加入无进展检测、原因码、持久化 checkpoint、TTL 和会话摘要。

  6. RAG Service API 与外部契约
     提供版本化查询、流式输出、会话、健康检查和就绪检查 API；传递租户/用户身份；定义 Dify、IAM、ONECRM、审批系统的接口契约，但不把这些外部系统实现在 RAG 内部。

  7. 可观测性、稳定性、性能与降级
     完善 Langfuse/链路追踪、指标脱敏、模型和索引版本记录；增加超时、重试、熔断、限流、并发控制、降级矩阵、压测和故障注入。

  8. 部署、安全加固与证据包
     补充容器、环境配置、密钥管理、非 root 运行、镜像锁定、漏洞扫描、迁移和回滚手册，并让每项企业能力都有测试或报告支撑。
