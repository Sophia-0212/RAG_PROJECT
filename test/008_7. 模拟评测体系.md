## 7. 模拟评测体系

### 7.1 Golden Set

共 2,400 条，经业务专家双人标注与仲裁：

| 分桶 | 数量 |
| --- | --- |
| 单轮事实 | 620 |
| 多轮指代/省略 | 360 |
| 字段名/错误码/缩写 | 310 |
| 多跳组合 | 260 |
| 版本/时间冲突 | 210 |
| 无答案与歧义 | 260 |
| 权限负例 | 240 |
| Prompt injection/恶意输入 | 140 |

其中 600 条用于开发和阈值选择，1,800 条锁定测试。按 source document 和问题模板分组切分，避免相邻 chunk 或同义问法跨集合。权限与安全用例必须 100% 通过才允许发布。

### 7.2 消融实验

固定同一生成模型、Prompt、知识快照和测试集：

| 方案 | Recall@10 | nDCG@10 | 正确率 | Groundedness | P95 | Token/请求 |
| --- | --- | --- | --- | --- | --- | --- |
| Dense only | 71.3% | 60.4% | 66.4% | 82.8% | 2.18s | 3,050 |
| Dense + Sparse RRF | 82.4% | 70.8% | 71.6% | 85.2% | 2.28s | 3,070 |
| + Cross-Encoder Rerank | 85.1% | 77.2% | 75.4% | 88.3% | 2.51s | 3,200 |
| + 按需自纠错 | 85.1% | 77.2% | 80.1% | 93.6% | 3.08s | 3,760 |
| 无条件两轮校验 | 85.4% | 77.1% | 80.5% | 93.8% | 4.85s | 4,980 |

结论：

- 混合检索主要改善 lexical-heavy 与多轮独立化后的召回。
- reranker 主要改善产品线、组织和版本错配。
- 自纠错不改变第一轮 Recall@10，而是提高证据充分性和生成忠实度。
- 按需自纠错比无条件两轮少 1.77 秒 P95、少 24.5% Token，只损失 0.4 个百分点正确率，因此选择前者。
